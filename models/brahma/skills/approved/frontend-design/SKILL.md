# Frontend Design

- Identify the user's primary task and make its next action visually obvious.
- Use the existing CodeVaa dark theme and `#D97757` accent where the app design system applies. Check the real project tokens before adding colors.
- Build hierarchy from spacing, type scale, contrast, and alignment. Avoid decorative effects that compete with content.
- Design loading, empty, error, success, and disabled states alongside the happy path.
- Keep forms label-driven, keyboard usable, responsive, and readable at 200% zoom.
- Use semantic HTML, visible focus, sufficient color contrast, and reduced-motion preferences.
- Reuse the project's components and tokens; add a new component only when it improves consistency or clarity.
- Preserve meaningful content at narrow widths. Avoid horizontal scrolling for ordinary app screens.
- For screenshot-driven work, describe the visible layout and content first; do not infer hidden behavior from pixels alone.
