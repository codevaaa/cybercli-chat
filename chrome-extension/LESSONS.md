# Browser workspace lessons

- A side panel can be opened as a full browser tab. Avoid stretching a narrow left-aligned account screen across a wide canvas.
- Separate the writing editor from its review region at wide widths; preserve a single natural flow in the actual narrow side panel.
- “No local matches” means the limited rules did not recognize a problem. It cannot certify grammar or justify a green success tick.
- Provider failures must preserve the draft and name the limited fallback. Source labels and explicit apply/undo make the result reviewable.
- A settings replacement must replace removed values too. Merging old paused domains into a replacement object can keep a site paused after reset.
- New providers need actual API documentation and configured server credentials. An analytics dashboard is not an inference endpoint. Logfare remains an explicit manual choice and never enters automatic writing/failover.
