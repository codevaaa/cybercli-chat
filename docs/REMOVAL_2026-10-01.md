# Standalone product removal — 1 October 2026

The standalone `agent-platform` product has been removed from this repository at the owner's request.

## Removed

- Entire runtime directory, including orchestration, task graphs, skills, local session storage code, tools, CLI, web UI, Electron wrapper, dependency installations and generated bundles.
- Main website's three product pages, settings/shortcut hooks, announcement component, navigation link, product-page banner and installer cards.
- Shared backend's product proxy/settings/history/feedback router and its three persistence models.
- Standalone-only hosted run endpoint; separate installer allowlist/catalog entries and installer fallback messaging.
- Dedicated desktop release workflow and obsolete setup/architecture instructions.

Unknown frontend URLs now return users to normal chat when authenticated, or the home page otherwise. The main website clears the removed settings cache and banner dismissal state on startup.

## Retained integrations

Normal chat, Playground, browser extension, main desktop, independent CyberCoder CLI/IDE integration, persona registry, workflows and Hunter are separate products. Shared completion, model, sub-agent and IDE endpoints remain available to them. Only `/agent/run` was specific to the removed hosted interface.
